Split Flap View

Editing Layer picks which image the controls affect: Full Flap spans the whole flap, Top/Bottom Half are optional overrides clipped to their half. Pick a layer, then use the file picker to load an image into it. Show this layer toggles it on/off; Remove Image clears it.
Drag to pan | Scroll wheel or +/- to zoom | Arrow buttons/keys nudge 1px | Rotate spins the image | Extend Edges repeats the top & bottom colors into the empty space (no distortion)
BG Fill fills empty space around images | Center snaps the active layer to its region
Detent W/H shows the side notches near the split (display only) | Export saves the full composited rectangle as PNG (no detent, bleeds to edge)
Quality renders at up to 8× for print-ready detail (PNG is lossless). To save straight into static assets, run python3 simulator/designer_server.py and open this page at http://localhost:8000/simulator/flap-designer.html, then set a Subfolder. Opened as a plain file, it downloads (or use Choose Folder in Chrome/Edge).
